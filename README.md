# HireHub

An AI-powered resume-checking project for reviewing one resume or processing multiple resumes together.

## Overview

HireHub aims to make resume review easier by supporting both individual and batch submissions. The repository includes frontend, backend, and data-preprocessing project folders.

## Features

- Review a single resume.
- Submit multiple resumes together for review.
- Separate frontend, backend, and data-preprocessing areas.
